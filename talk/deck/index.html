Why it failed

None of that was the model being unintelligent.

No world model

Asked “is it patched?”, the only place it can look is its own earlier output. It grades its own homework from memory. There is no state it can query.

it remembered, where it needed to check

No graph

Everything it knew was held in its short-term memory — and that memory fills up and gets dropped. The record of what it had already done simply vanished.

no memory that outlives the job

No verification

Nothing stood between deciding and doing. Every step was taken on trust, so small errors pile up instead of showing up.

step 90 rests on 89 things nobody checked

Long-horizon isn’t just more steps — it’s steps that depend on each other. At 99% per step, a 100-step job succeeds 36% of the time.

The real bottleneck

Why hasn’t any of this transformed the economy yet?

The models are extraordinary. The benchmarks are remarkable. And yet remarkably little real work has actually moved. It is worth asking why.

Not reliable

Ask the same question twice, get two different answers. You cannot build a process on something that behaves differently each time you run it.

Not reproducible

If you cannot repeat a result, you cannot test it, and you cannot investigate it when it goes wrong. It can never become a procedure.

Not accountable

It cannot show you its work in a way you can check. And when it is wrong, it is wrong with exactly the confidence it has when it is right.

So we use it for drafts and suggestions, and keep it away from anything that matters. The barrier to adoption was never intelligence — it was trust. And trust is an engineering problem.

The fix

Give it the three things it was missing.

Neural proposes. Symbolic disposes.

What opens up

The moment the work is verifiable, the job description changes.

Not because the model got smarter — because you can finally trust a hundred-step result.

Cybersecurity

Fleet-wide remediation that can prove coverage. 3am incident response with an audit trail you’d show a regulator. Multi-day campaigns that can say exactly what they touched.

Research

Literature → hypothesis → experiment → replication, where every step is reproducible. Reproducibility isn’t a nice-to-have in science — it’s the whole product.

Digital employees

Multi-day workflows with real consequences — migrations, onboarding, close-the-books. The blocker was never intelligence. It was that nobody could audit the work.

Every one of those is gated on the same question: can you verify what it did?

Cybersecurity · what a security team actually gets

The difference between an agent you demo and one you let near prod at 3am.

Coverage you can prove

The opening agent reported 212 swept and actually swept 148. With a graph, coverage stops being a claim and becomes a query — which hosts are verified swept, which are verified isolated, and which edge proves it.

Incident response you can replay

Determinism means the 3am run and the postmortem two weeks later produce the same answer. You can’t root-cause a system that answers differently every time.

Provenance per decision

Every edge records which layer decided — symbolic fact, learned statistic, or model guess. “Why did the agent do that?” has an answer, per action.

Blast radius, bounded

Irreversible actions — deploys, key rotation, privilege grants, takedowns — don’t fire on unverified preconditions. The refusal is the control.

Long-horizon security work is exactly the shape this fits: many steps, high blast radius, formalizable actions, and somebody will eventually ask you to prove what happened.

What you get

Three properties a sampled model cannot give you.

Reliability

The failure mode changes: a wrong model acts confidently, this one refuses — and refusal is recoverable in a way a bad deploy is not.

100% vs 92% (LATS) / 64% (ReAct) on multi-step planning

Reproducibility

Same input, same plan, every run. Zero variance across seeds — which is what makes an agent testable at all.

regression-test it · bisect it · replay an incident

Auditability

Every refusal names the exact missing fact — not “the model seemed unsure,” but a named, checkable gap.
